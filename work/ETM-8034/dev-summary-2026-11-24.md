## 1. สีของแถวที่ถูกเลือกเหมือนกันทุก Level (L1–L4)

**ก่อนแก้:** เลือกแถว L1 (Platform) หรือ L2 (Work Header) แล้ว**ไม่ขึ้นสีฟ้า** และช่อง No. ของ L1/L2 ไม่มี cursor รูปมือ ไม่มีสีตอน hover ไม่มีกรอบตอน focus
**หลังแก้:** L1/L2 เลือกแล้วขึ้นสีฟ้าเหมือน L3/L4 ทุกอย่าง

**เคสที่ต้องเทส**
- เลือกแถว L1, L2, L3, L4 ต้องขึ้นสีฟ้าเหมือนกันทั้งช่องธรรมดา ช่อง read-only และช่อง No.
- ถ้าแถวนั้นมี Highlight Row อยู่ (มีสีพื้น) แล้วเลือกแถวนั้น สีที่ได้ต้องดูสมเหตุสมผล ทั้ง L1/L2 และ L3/L4
- เลือกแถวแล้วเลื่อนตารางไปทางขวา ช่อง No. ที่ล็อกไว้ต้องยังบังคอลัมน์ที่เลื่อนลอดอยู่ข้างใต้ ตัวเลขต้องไม่ทับกัน และต้องเช็คทุก Level

## 2. การคลิกคอลัมน์ "No."

| การกระทำ | ผลที่ควรได้ |
|---|---|
| **คลิก 1 ครั้ง** | เลือก**เฉพาะช่อง No.** (ขึ้นสีฟ้า) แถวไม่ถูกเลือก และ **Histogram ไม่ filter** |
| **คลิกซ้ำช่องเดิม** | ยกเลิกการเลือกช่องนั้น |
| **ดับเบิลคลิก** | เลือก**ทั้งแถว** และ Histogram filter ตามแถวนั้น กด Ctrl+C แล้วต้อง copy ได้ทั้งแถว |
| **ดับเบิลคลิกแล้วคลิกช่อง No. เดิมอีกครั้ง** | ยกเลิกการเลือกทั้งหมด ทั้งช่อง No. และช่องข้อมูลของแถว |
| **Shift + คลิก** | เลือกช่อง No. เป็นช่วงต่อจากช่องที่คลิกล่าสุด |
| **Shift + ดับเบิลคลิก** (หรือดับเบิลคลิกก่อนแล้วตามด้วย Shift + คลิก) | เลือกทั้งแถวเป็นช่วง ช่อง No. ทุกแถวในช่วงต้องขึ้นสีฟ้าด้วย |
| **Ctrl/Cmd + คลิก** | เพิ่มหรือเอาช่อง No. นั้นออก โดยที่ที่เลือกไว้แล้วยังอยู่ |
| **Ctrl/Cmd + ดับเบิลคลิก** | เพิ่มทั้งแถวเข้าไปในที่เลือกไว้ แถวเดิมยังอยู่ |
| **Ctrl + คลิกแถวที่เลือกไว้แล้ว** | เอาเฉพาะแถวนั้นออก แถวอื่นยังอยู่ |

**จุดที่เปลี่ยนจากเดิมและต้องเทสให้ชัด:** เมื่อก่อนคลิกครั้งเดียวที่ No. แล้วแถวถูกเลือกและ Histogram filter ตาม (หน่วงประมาณ 0.3 วินาที) ตอนนี้ต้อง**ดับเบิลคลิก**เท่านั้น Histogram ถึงจะ filter

## 3. คลิกช่องที่เลือกอยู่แล้วเพื่อยกเลิก (ทั้งตาราง)

ใช้กับ**ทุกช่อง** ทั้งใน Gantt และใน Histogram: คลิกช่องที่เลือกอยู่แล้วอีกครั้ง ช่องนั้นจะหลุดจากการเลือก (เมื่อก่อนค้างไว้)
- ต้องเช็คด้วยว่าการแก้ไขช่องข้อมูล (inline edit) ยังทำได้ปกติ

## 4. เฉพาะ macOS: Ctrl + คลิก

บน Mac ปกติ Ctrl + คลิกจะเปิด context menu (เหมือนคลิกขวา) ตอนนี้ใน Gantt **Ctrl + คลิกจะเลือกช่องแทน** และทำงานเหมือนข้อ 2 รวมถึง Ctrl + คลิก 2 ครั้งเร็ว ๆ ที่ช่อง No. ซึ่งนับเป็นดับเบิลคลิก
- **คลิกขวาจริง ๆ** (two-finger click หรือปุ่มขวาของเมาส์) ต้องยังเปิด context menu ได้ตามปกติ
- ⚠️ ข้อควรรู้: Ctrl + คลิกช่องไหนก็ได้ใน Gantt บน Mac จะไม่เปิดเมนู ไม่ใช่แค่ช่อง No. ตั้งใจออกแบบไว้แบบนี้ แต่ขอ QA ยืนยันว่ารับได้

- ทดสอบทั้ง Windows (Ctrl) และ Mac (Cmd และ Ctrl)
