# ETM-8049 [Improvement] View Worklist Table - Working Location Columns
Status: Refinement
Subtasks: 
Links: Relates ETM-686, Relates ETM-1106, Relates ETM-8391, Relates ETM-564, Relates ETM-17, Relates ETM-8391, Relates ETM-1008, Relates ETM-6843, Relates ETM-2310, Relates ETM-2312, Relates ETM-2615, Relates ETM-8050

## Description
**As a:** Turnaround Manager or Job Owner  
**I want to:** view and filter works in the worklist by Working Location (Deck, X, Y)  
**So that:** I can find and review works by where they are performed on the platform.

Ref: [ETM-434](https://pttep.atlassian.net/browse/ETM-434)

---

## **Pre-Conditions**

* A user must be successfully **logged into the system** and possess the **View Worklist** permission in [Role & Permission](https://pttep.sharepoint.com/:x:/r/sites/TurnaroundManagement/Shared%20Documents/03%20Development/Role%20%26%20Permission%20V.2.xlsx?d=wa5e5a9a2071b4ed7b3ef83c4cf0dffd9&csf=1&web=1&e=3stFwC).
* The user must have opened the **Worklist page** by clicking the **Worklist Item** in a Plan Card on the **Planning tab** of a specific Shutdown Event. (Aligned with [ETM-5265](https://pttep.atlassian.net/browse/ETM-5265))

## **Acceptance Criteria**

1. **Column Customization:**

    1. The **Working Location (Deck)**, **Working Location (X)** and **Working Location (Y)** fields must be included as options within the Column Customization menu, allowing users to enable them manually. However, they must remain hidden and not be displayed in the default view of the table. (Aligned with [ETM-2228](https://pttep.atlassian.net/browse/ETM-2228) AC 10)
    2. The three columns are added in this order: Deck, X, Y. The column layout is saved per user (Aligned with [ETM-564](https://pttep.atlassian.net/browse/ETM-564) AC 6):
    
        * **Default layout** (the user has never customized the columns, or clicks **Reset**): the three columns are placed **between Department and Manpower Resource**.
        * **Saved custom layout** (the user has reordered columns before): the three columns are placed **immediately after Department**, wherever Department currently is.
        * In both cases the columns are added hidden (unchecked), per AC 1.1.
        
    
2. **Cell Display:**

    1. A work with multiple values in a field must display all values in one cell, separated by a comma and a space (e.g., `Main Deck, Cellar Deck`). A work's values are all the Working Location values of its Work Breakdowns (Aligned with [ETM-17](https://pttep.atlassian.net/browse/ETM-17) AC 2). Values are shown as stored; only identical values are shown once.
    2. Values must be ordered as follows: values from the Master Data first, following the Master Data sort order; then free-text values, sorted alphabetically (A to Z) using the system-wide alphabetical sort (`localeCompare('en', { numeric: true })`). Free-text values apply to Working Location (Deck) only.
    3. If the text exceeds the column width, it must end with an ellipsis (…). Hovering over it must display the full content. (Aligned with [ETM-434](https://pttep.atlassian.net/browse/ETM-434) AC 6)
    
3. **Column Filter:**

    1. Each of the three columns must include a column filter as a **checkbox list** with a search box and **Select All**, the same as other columns. (Aligned with [ETM-434](https://pttep.atlassian.net/browse/ETM-434) AC 5)
    2. The filter options must list each **individual value** found in the worklist (a cell with `Main Deck, Cellar Deck` contributes two options), without duplicates.
    3. **Matching rule:** A work must be displayed if **any one** of its values matches a selected option.
    4. **Option order:** Same as AC 2.2 — Master Data values in Master Data order first, then free-text values A to Z.
    5. **No Blank option:** The filter must not include a `-` (Blank) option, because all three fields are mandatory.
    6. **Letter-case variants (Deck):** Filter options are listed exactly as stored. If the data contains Deck values that differ only by letter case (e.g., older data), each spelling is shown as a separate option.
    
4. **Sorting:** The new columns do not support column sorting. The default row order of the table remains unchanged. (Aligned with [ETM-1467](https://pttep.atlassian.net/browse/ETM-1467))
5. **Export:** No change. The Export Worklist file already includes these three fields. (Ref: [ETM-1108](https://pttep.atlassian.net/browse/ETM-1108))
6. **Letter-case Normalization when Saving Deck Values:**

    1. When a free-text Working Location (Deck) value is saved through **any entry point**, a value that matches a Master Data value (ignoring letter case) is converted to the Master Data spelling. (Aligned with [ETM-1106](https://pttep.atlassian.net/browse/ETM-1106) AC 7, [ETM-1230](https://pttep.atlassian.net/browse/ETM-1230)) Entry points:
    
        * **Work Registration:** Create Work, Edit Work and Work Breakdown edit, by typing or pasting
        * **Excel import:** Create Multiple Work via Excel Import ([ETM-1008](https://pttep.atlassian.net/browse/ETM-1008), [ETM-1106](https://pttep.atlassian.net/browse/ETM-1106)) and Import Work and Work Breakdown from Excel ([ETM-6843](https://pttep.atlassian.net/browse/ETM-6843))
        * **Shutdown Logic:** Edit by Gantt Table ([ETM-2310](https://pttep.atlassian.net/browse/ETM-2310)), Edit by Modal ([ETM-2312](https://pttep.atlassian.net/browse/ETM-2312)) and Gantt Table Copy & Paste ([ETM-2615](https://pttep.atlassian.net/browse/ETM-2615))
        
    2. Otherwise, if it matches (ignoring letter case) a Deck value already used by another work in the same worklist, it is converted to the spelling used by the earliest-created work in this worklist.
    3. **When the conversion is shown:** On screens where the user types or pastes, the converted spelling is shown in the field as soon as the value is entered, before saving. (Aligned with [ETM-1230](https://pttep.atlassian.net/browse/ETM-1230), [ETM-7351](https://pttep.atlassian.net/browse/ETM-7351)) For Excel import, the converted spelling is the value that is saved.
    4. **Several new spellings in one save:** If one save contains values that differ only by letter case and match neither Master Data nor any other work in the worklist, they are all converted to the spelling entered first (the topmost Work Breakdown, or the first row of an import file).
