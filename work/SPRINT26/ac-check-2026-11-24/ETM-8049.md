## Problems

### TC vs AC / BA

1. **AC 6.1 "Edit Work" (Q26, open).**
   - 8785: the summary and data row 1 say "Edit Work Details of WK-1a, MAIN DECK".
   - 8791 step 10: "Open Edit Work Details ... type the 31-character value in the Deck field".
   - 8793 steps 5-6: "Open Edit Work Details of WK-18 and remove the tag".
   - The app has no Deck field on Edit Work Details, so these steps cannot be run as written. The Xray text must be changed after the BA answers.
2. **8788 cannot be run as written.**
   - Steps 2, 7 and 8 type into "the first/second/third Work Breakdown row" of Create Work. Step 10 then expects one work with the cell `Main Deck, Cellar Deck, Dock Area, DOCK AREA`.
   - The script note says Create Work has one row per work (Entry.spec:76), so the TC describes a flow that does not exist.
3. **Y `a` becomes `A` (8786, 8787) has no AC behind it.**
   - AC 6 talks only about Deck. X and Y are "From list".
   - The Q17 answer was not recorded. Confirm it or remove the step.
4. **Open assumptions in the TCs although the questions are marked answered:**
   - 8775: "ASSUMPTION Q3" (the table changes before or after Apply).
   - 8788 step 8: "ASSUMPTION Q16" (blur commits the value).
   - 8777 steps 9-10: "ASSUMPTION: concurrency was not answered by the BA".
   - Either the answers were never written into the TCs, or the questions are not really answered.
5. **8784 depends on data the QA team does not own.** It uses work `BATEST8049A` in the BA's plan "ZZ BA Claude Test - FSD 8 days".

### Scripts

6. **8781 TC-008 Select All with a search is weak.**
   - `refA` is recorded but never compared (Cells.spec:164).
   - Step 11 only checks `rows.length > 0` (Cells.spec:179).
   - Step 12 compares only `rel` and a boolean "rows > 0" (Cells.spec:185).
   - The TC asks that the result "follows the same rule as reference A/B". The handoff reports 0 rows here (a possible app bug, not logged).
7. **8785 TC-012 can be PASSED in Xray with half its data rows not run.**
   - Only the Edit Breakdown row is scripted (Entry.spec:43-72).
   - The annotation type is `ba-confirm`, which is not in `NOT_PROVEN` (fixtures/pageFixtures.ts:19). So the test PASSED in run 5 although TC row 1 (Edit Work Details) was never run.
8. **8788 TC-015 can PASS without checking the TC's step 10.**
   - The script makes 3 works and checks `Main Deck, DOCK AREA`, `Dock Area` and `Cellar Deck` (Entry.spec:131-135). The TC expects one 4-value cell.
   - Step 8 (blur) is only recorded. The script then re-enters the value with Enter (Entry.spec:115-123).
   - The annotation is `ba-confirm` only, so the test is not marked as not proven.
9. **8793 TC-020 does not match the TC.**
   - The script adds a step the TC does not have, "add Helideck" (Entry.spec:296-305).
   - The final check (Entry.spec:314) expects `HELIPAD, Helideck, Main Deck`, sorted as a set. The TC expects `Main Deck, HELIPAD`.

   - The annotation is `ba-confirm` only, so it can be PASSED with steps that differ from the Xray steps.
