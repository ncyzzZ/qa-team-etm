That answer exists only in `.claude/team/work/ETM-8003/story.md` (given through the user). There is no Jira comment, and ETM-4127 AC6 still says "reduces the line to one point". Ask the BA to record it in Jira so the expected results have a written source.
- All 4 round-2 questions (`questions-for-BA-round2.md`) are answered in story.md. None are open.

**Scripts that can pass without checking the TC**
- 8800 step 3 and 8801 step 2 (dashed or solid) never fail: `dashNote` only adds an annotation (SPEC:72-80, :116, :134). `ac-strength.json` says "stroke hex and dash asserted": that is stale, from the old SVG reader.
- Label checks need only 1 exact pixel (`MIN.label: 1`, sCurvePage.ts:37). That proves the color is drawn somewhere, not that every label has it.
- 8809: TC step 3 says only the active-date labels show and the others are hidden. `labelNote` never fails (SPEC:41-49, :401). 8808 has the same gap for Show Only Today (SPEC:326, :336, :352).
- 8802: the TC selects Show Plan(%) and Show Actual(%) = Show All (TC steps 2-3). The script checks the labels in the default Show Only Today state (SPEC:153-188).
- No script asserts the Filter Panel default state (Day / Show Only Today / Show Only Today) or that Reset returns to it. This is TC step 1 in 8802/8808/8809 and step 10 in 8808.
- Steps that pass when env data is missing:
  - 8804 steps 4-7 (frozen and not-frozen dates, SPEC:231-249).
  - 8806 step 3 (SPEC:278).
  - 8807 steps 2-3 (View Active login, SPEC:297, :303).

  These steps get a `partial` note but the test stays PASSED. The evidence report only shows the note (`tools/evidence-report-v4.mjs:27`). Unlike ETM-7343's `Run.done()`, nothing turns these into skipped. Risk: a PASSED result in Xray for a step that was never checked.
