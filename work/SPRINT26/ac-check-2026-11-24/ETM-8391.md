## Problems

### TC vs AC / BA

1. **Most TCs were not updated for AC 5 (17 Nov): "The Remark filter starts with Select All (all options selected)".**
   - 8655 step 1: "tick `Note 2` → option is ticked", then step 2: "only W06".
   - 8649 step 11: "Tick only `Note 1`".
   - 8656 step 5: "Tick `Select All` → the three Note options are ticked".
   - 8658 step 2: "tick `Note 1` and `Note 2`".
   - 8662 step 1: "tick `Valve A, B`".
   - All of these assume an empty start. With every option already ticked, a manual tester gets different results.
   - The scripts work around it with `pickOnly()` (spec:42-51), but the Xray steps still need "untick Select All first".
2. **Nothing-ticked behaviour (Q6) is not consistent between TCs.**
   - 8649 step 12 and 8655 step 3 expect "All works are shown again".
   - 8655 steps 11, 16 and 22 expect "the same as the Job Description reference".
   - The scripts also disagree: spec:110 asserts all 20 rows, but spec:299 asserts the JD nothing-ticked reference.
   - Both can only be right if the JD reference shows all rows. The Q6 answer is not recorded.
3. **8650 step 8 gives the symbol group order as " Test, ` - `, `- `, `- a`, `--`, `(Hold)`, `#Urgent`".**
   - localeCompare('en', {numeric:true}) gives `" - ", " Test", "- ", "- a", "--", "(Hold)", "#Urgent"` (I checked this with node).
   - Step 11 and the script (spec:573) use the real localeCompare, so only the TC text is wrong.
4. **8663 cannot be run as written.** Steps 1-2 must be done "before the release", and QA already has the release. The TC needs a different way to set up the old state.

### Scripts

5. **Stale `partial` annotations make tests that are fully scripted never PASS:**
   - 8651 (spec:135): "guessed field labels: check after the first run". It has already run.
   - 8653 (spec:228): "assumptions". It has not run yet (needs `PATHS.edit`).
   - Remove them once the selectors are confirmed, or these TCs can never be PASSED by script.
6. **8656 step 11** (spec:367): `tickSelectAll(page).catch(() => undefined)`. If the click fails, the "row count unchanged" check still passes, so the test can pass without ticking anything.
7. **8663 is weak** (spec:685-691).
   - The "old" state is built from guessed address keys (`wsRemarkType=contain`, `wsRemarkValue`). If these were not the real old keys, the test proves nothing.
   - It is partial, so always skipped, which is correct. It still needs a manual check with a real pre-release address, or the old key names from the dev.
8. **8650 step 8** (spec:561) groups options with its own regex `grp()` (spec:500). This is a looser check than the TC's exact list. It is fine because spec:573 also checks the full localeCompare order.
9. **8658** (spec:406) hard-codes `19` distinct options. It breaks if the shared worklist data changes. Not a false pass.
10. **8655** (spec:293-295) builds the JD reference outside any step, so the evidence report has no picture of it.
