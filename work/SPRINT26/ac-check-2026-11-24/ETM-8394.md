## Problems
1. **New AC 4 row-level rule (23 Nov) contradicts the TCs and the script.**
   - The script writes Work Status to column `BJ` on the Work row and Breakdown Status to `BK` on the breakdown row (`importStatus.helpers.ts:107`, `:113`).
   - It reads a per-breakdown status from a guessed column `sab_status` (`helpers.ts:31`, `:157-159`, `:179-182`).
   - The helper comment says the Work row has `sdw_breakdown_status`, which fits the new AC (Breakdown Status is a Work-level field).
   - TCs affected: ETM-8735 (B1 with 3 statuses), 8742 (D2), 8746 (J1 with 3 statuses), 8747 (table 6b per breakdown), 8754 (Q2), 8756, 8757 (rows 5-7), 8765, 8755, 8768, 8769.
   - Ask BA, with an example: does the Breakdown Status on the Work row set every breakdown of that Work? Then rewrite the TCs and the `Sheet` helpers.
2. **New AC 1.3: no TC for "Job Owner cannot import into a frozen Worklist".** ETM-8768 covers only the Turnaround Manager. It needs env data, has hard-coded ids (`spec.ts:1248-1249`) and is not repeatable.
3. **New AC 3.3.1-3.3.3 comparison rules have no TC:**
   - trailing spaces mean no change;
   - case-only change in a master-data field means no change;
   - case-only change in Work Header or another free-text field means "Updated".
4. **AC 3.4 "every such row": not tested.** ETM-8766 never puts the deleted Work and its breakdown rows in one file. The script only checks the first matching row (`spec.ts:1106`, `:1132`). ETM-8766 step 2 also expects "1 data validation errors", which is right only for its single-row file.
5. **Script risks.**
   - **Status values are guesses.** All status codes (`'U','CR','IR','RD','REQUIRED'`) and the breakdown status column are UNVERIFIED guesses (`helpers.ts:25-31`). A wrong guess fails rather than passes, but every DB assertion is unproven.
   - **Swallowed click.** ETM-8756 step 6 swallows the dropdown click error (`spec.ts:813`, `.catch(() => undefined)`) and then expects 0 options. The step can pass when the click fails for another reason. This was flagged in `script-quality.md` and is still there.
   - **Unverified selectors.** The export button and the template-download selector are unverified (8755, 8765).
   - **Wrong row count.** ETM-8746 says "twenty rows"; the script asserts 16 (`spec.ts:398`, `:413`). Fix the Xray step.
6. **Stale review.** `ac-strength.json` (19 Nov) rates AC-1..8 "strong", but nothing has been run, and it predates the 23 Nov AC change. Treat it as out of date.
