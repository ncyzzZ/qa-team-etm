# ETM-8391 [Improvement] View Worklist Table - Remark Column Filter
Status: Refinement
Subtasks: 
Links: Relates ETM-8049, Relates ETM-8049, Relates ETM-8050

## Description
**As a:** Turnaround Manager or Job Owner  
**I want to:** filter the Remark column by selecting values from a checklist  
**So that:** I can filter Remark the same way as every other column in the worklist.

Ref: [ETM-434](https://pttep.atlassian.net/browse/ETM-434)

---

## **Pre-Conditions**

* A user must be successfully **logged into the system** and possess the **View Worklist** permission in [Role & Permission](https://pttep.sharepoint.com/:x:/r/sites/TurnaroundManagement/Shared%20Documents/03%20Development/Role%20%26%20Permission%20V.2.xlsx?d=wa5e5a9a2071b4ed7b3ef83c4cf0dffd9&csf=1&web=1&e=3stFwC).
* The user must have opened the **Worklist page** by clicking the **Worklist Item** in a Plan Card on the **Planning tab** of a specific Shutdown Event. (Aligned with [ETM-5265](https://pttep.atlassian.net/browse/ETM-5265))

## **Data Source**

The data on this page is retrieved from the **Work Repository**, filtered by the specific **Worklist**:

| **Field Name** | **Data Type** | **Data Validation** |
| --- | --- | --- |
| Remark | Text | Free-text; not mandatory |

## **Acceptance Criteria**

1. **Filter Type:** The Remark column filter must be a **checkbox list** with a search box and **Select All**, the same as other columns. It replaces the current text filter (Contains / Blank / Not blank). (Aligned with [ETM-434](https://pttep.atlassian.net/browse/ETM-434) AC 5)
2. **Filter Options:**

    1. The list must show each distinct Remark value found in the worklist. Values are listed exactly as stored; values that differ in letter case or in leading/trailing spaces are separate options. (Aligned with [ETM-8049](https://pttep.atlassian.net/browse/ETM-8049) AC 3.6)
    2. **Blank:** If any work has an empty Remark, the list must show a `-` option representing Blank. The `-` option must always be the first option, directly under **Select All**, and is not included in the alphabetical sort. Blank includes an empty Remark, a Remark made only of spaces, and a Remark that is literally `-`.
    3. **Option order:** After `-`, all other options must be sorted alphabetically (A to Z) using the system-wide alphabetical sort (`localeCompare('en', { numeric: true })`).
    
3. **Long Text:** The list may be long; the user can scroll within the filter. Options longer than the filter width must end with an ellipsis (…), and hovering over an option must display the full text. Table cells keep the existing behavior: ellipsis with the full text on hover. (Aligned with [ETM-434](https://pttep.atlassian.net/browse/ETM-434) AC 6)
4. **Filter Result:** Only works whose Remark matches a selected option are displayed; selecting `-` displays works whose Remark is Blank (per AC 2.2).
