# ETM-8394 [Improvement] Import Work and Work Breakdown - Import Work Status and Breakdown Status
Status: Open
Subtasks: 
Links: Relates ETM-8526

## Description
**As a** Turnaround Manager  
**I want to** set the Work Status and Breakdown Status when I import Works and Work Breakdowns from Excel  
**So that** Works that were already reviewed outside the system keep their status and do not all restart from `New`.

Ref: [ETM-6843](https://pttep.atlassian.net/browse/ETM-6843)

---

**Pre-Conditions**

* The user is logged into the STMS application and possesses the **Import Work** permission in [Role & Permission](https://pttep.sharepoint.com/:x:/r/sites/TurnaroundManagement/Shared%20Documents/03%20Development/Role%20%26%20Permission%20V.2.xlsx?d=wa5e5a9a2071b4ed7b3ef83c4cf0dffd9&csf=1&web=1&e=3stFwC).
* The user is importing a file through the **Import Work and Work Breakdown** workflow ([ETM-6843](https://pttep.atlassian.net/browse/ETM-6843)).

---

**Data Source**

* **Import Template**: `Work Status` and `Breakdown Status` columns in `Worklist_Data` ([ETM-6843](https://pttep.atlassian.net/browse/ETM-6843)).
* **Status values**: Work Status and Breakdown Status values defined in [ETM-846](https://pttep.atlassian.net/browse/ETM-846).

---

**Acceptance Criteria**

1. **Who Can Import Status**:

    1. Only a **Turnaround Manager** can set `Work Status` and `Breakdown Status` through import.
    2. When a **Job Owner** imports, the two status columns are ignored without any message, even if they contain values.
    
2. **Action = Add**:

    1. If the Turnaround Manager fills in a status, the new Work / Work Breakdown is created with that status.
    2. If the status cell is blank, or the importer is a Job Owner, the status is `New` (Work) and `Breakdown Updated` (Breakdown), as in [ETM-846](https://pttep.atlassian.net/browse/ETM-846) AC 3–4.
    
3. **Action = Revise**:

    1. If the Turnaround Manager fills in a status, the record is updated to that status.
    2. If the status cell is blank, or the importer is a Job Owner, the status follows the automatic triggers in [ETM-846](https://pttep.atlassian.net/browse/ETM-846) AC 5 (e.g. a revised Work at `Reviewed` becomes `Updated`).
    
4. **Any Status and Any Combination**: Any Work Status (except `Deleted`) and any Breakdown Status from [ETM-846](https://pttep.atlassian.net/browse/ETM-846) can be imported, in any combination. The transition order in [ETM-846](https://pttep.atlassian.net/browse/ETM-846) AC 3–4 is **not** checked during import (e.g. Work `Ready` with Breakdown `Breakdown Updated` is accepted).
5. **Deleted Status Not Allowed**: `Deleted` cannot be imported as a Work Status. A Work is deleted only through `Action = Delete` ([ETM-6843](https://pttep.atlassian.net/browse/ETM-6843)).
6. **Master Data Validation**: If a status cell contains a value that is not in the master data (sheet `Dropdown Options`), the system flags a validation **Error** on that cell: _"The value you entered does not match with Master Data. Please check the sheet name “Dropdown Options”."_ (Aligned with [ETM-6843](https://pttep.atlassian.net/browse/ETM-6843) import validation). There is no other status validation.

---

**UI Design**

* No UI layout change. Uses the existing import template and import result screens ([ETM-6843](https://pttep.atlassian.net/browse/ETM-6843)).
