# ETM-8388 [Improvement] Shutdown Timeline - Table Copy and Paste Support

## Description
**As a** Turnaround Manager  
**I want to** copy and paste data in the Shutdown Timeline table on the Timeline screen and the Edit Plan screen  
**So that** I can fill in status, weekly progress and the preparation plan quickly from Excel or from other rows, instead of typing every cell.

Ref: [ETM-7345](https://pttep.atlassian.net/browse/ETM-7345) · [ETM-7348](https://pttep.atlassian.net/browse/ETM-7348) · [ETM-7349](https://pttep.atlassian.net/browse/ETM-7349) · [ETM-8405](https://pttep.atlassian.net/browse/ETM-8405)

**Acceptance Criteria**

1. **Common Copy & Paste Rules (both screens)**:

    1. **Copy**: `Ctrl+C` / `Cmd+C` copies the selected cells to the clipboard as tab-separated values that can be pasted into Excel.
    2. **Paste Modes**: Pasting while a cell is focused (Focus Mode) or while a cell is in edit mode (Edit Mode) behaves the same: the clipboard data is mapped across the grid starting from the active cell as the top-left anchor. (Aligned with [ETM-7351](https://pttep.atlassian.net/browse/ETM-7351) AC 2.1)
    3. **Activity Group Scope**: A paste operation applies only within the Activity Group that contains the anchor cell. Pasted data never flows into another Activity Group. (Aligned with [ETM-7351](https://pttep.atlassian.net/browse/ETM-7351) AC 4.1)
    4. **Copy Across Activity Groups**: The user can select and copy cells that span more than one Activity Group. The copied data skips the Activity Group header rows and contains activity rows only. The paste still applies within the anchor's Activity Group (AC 1.3).
    5. **Invalid Values**: A pasted value that fails validation is not applied and the cell is **cleared**. If the field is mandatory, the cleared cell shows the red background (`#FFCCC7`) and `[ Save ]` is disabled until it is fixed. The `Paste Validation Failed` modal is shown once per paste action. (Aligned with [ETM-7351](https://pttep.atlassian.net/browse/ETM-7351) AC 3.1)
    6. **Unsaved Changes**: A paste marks the screen as having unsaved changes (`isDirty = true`), the same as manual editing.
    
2. **Timeline Screen**:

    1. **Status Column**:
    
        * **Copy**: The user can copy a single `Status` cell or several `Status` cells down the column.
        * **Paste**: Data can be pasted into the `Status` column only. Each value must be `Open` or `Close` (case-insensitive) and is converted to the official spelling.
        * If the pasted data has more rows than the remaining activities in the anchor's Activity Group, the extra rows are ignored (activities cannot be added on the Timeline screen).
        
    2. **Weekly Cells**:
    
        * **Copy**: The user can copy a single weekly cell, or a range of weekly cells within **one row**, from either the weekly `Plan (%)` row or the weekly `Actual (%)` row. Selecting cells from two rows at once (e.g., `Plan (%)` and `Actual (%)` together, or two activities) is not allowed.
        * **Paste**: Data can be pasted into weekly `Actual (%)` cells only. Weekly `Plan (%)` cells on the Timeline screen are read-only.
        * Pasted values follow the weekly `Actual (%)` input rules in [ETM-7349](https://pttep.atlassian.net/browse/ETM-7349) AC 2.4 (truncate to 1 decimal place, clamp above `100.0`, invalid input leaves the cell blank).
        * Pasted values that would land in a future week (after the Current Week, which is locked per [ETM-7349](https://pttep.atlassian.net/browse/ETM-7349) AC 2.3) are cut off and not applied.
        
    
3. **Edit Plan Screen**:

    1. **Table Columns (**`Activity` to `End Date`):
    
        * **Copy & Paste NxN**: The user can copy and paste an `NxN` range across `Activity`, `Action By`, `Focal Point`, `Start Date` and `End Date`.
        * `Plan (%)` is **not** included in copy & paste. It can be changed by typing, or is recalculated from the weekly `Plan (%)` ([ETM-8405](https://pttep.atlassian.net/browse/ETM-8405) AC 2).
        * **Field Rules**:
        
            * `Activity` (max 500), `Action By` (max 50), `Focal Point` (max 50): longer values are truncated to the maximum length. (Aligned with [ETM-7348](https://pttep.atlassian.net/browse/ETM-7348) AC 3.1)
            * `Start Date` / `End Date`: must be a valid date in `D Mon YYYY` or `DD Mon YYYY`; otherwise the value is not applied. `Start Date <= End Date` applies (Aligned with [ETM-7348](https://pttep.atlassian.net/browse/ETM-7348) AC 4.3). An empty mandatory cell shows the red background and disables `[ Save ]` (Aligned with [ETM-7348](https://pttep.atlassian.net/browse/ETM-7348) AC 4.2).
            * Pasting `Start Date` or `End Date` recalculates the activity's weekly `Plan (%)`. (Aligned with [ETM-8405](https://pttep.atlassian.net/browse/ETM-8405) AC 3)
            
        * **Automatic Activity Creation**: If the pasted data has more rows than the remaining activities in the anchor's Activity Group, the system adds new activities at the bottom of that Activity Group for the extra rows. New activities use the default values from [ETM-7348](https://pttep.atlassian.net/browse/ETM-7348) AC 2.1 (`Plan (%) = 0.0`, `Status = Open`); fields not covered by the paste stay empty. (Aligned with [ETM-7351](https://pttep.atlassian.net/browse/ETM-7351) AC 4.2)
        
    2. **Weekly Cells**:
    
        * **Copy**: The user can copy a single weekly cell, or a range of weekly cells within **one row**, from either the weekly `Plan (%)` row or the weekly `Actual (%)` row.
        * **Paste**: Data can be pasted into weekly `Plan (%)` cells only, following the input rules in [ETM-8405](https://pttep.atlassian.net/browse/ETM-8405) AC 1.5.
        * **Editable Range Only**: Only weeks within the activity's `Start Date` – `End Date` range are editable ([ETM-8405](https://pttep.atlassian.net/browse/ETM-8405) AC 1.1). Pasted values that would land outside this range are cut off and not applied.
        * After the paste, the activity's `Plan (%)` is recalculated as the sum of its weekly values. (Aligned with [ETM-8405](https://pttep.atlassian.net/browse/ETM-8405) AC 2)
