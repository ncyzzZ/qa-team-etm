# ETM-8521 [Improvement] Shutdown Logic - Faster Copy & Paste in Gantt Table
Status: Open
Subtasks: ETM-8533 [FE] Improve performance copy & paste logic [Done]
Links: Relates ETM-8035

## Description
**As a** Turnaround Manager  
**I want** pasting data into the Shutdown Logic Gantt table to complete faster  
**So that** I can mass-update large Shutdown Logic plans without waiting for the table to process the paste.

Ref: [ETM-2615](https://pttep.atlassian.net/browse/ETM-2615)

---

**Pre-Conditions**

* The user possesses the **Edit Shutdown Logic Table and Visualization** permission in [Role & Permission](https://pttep.sharepoint.com/:x:/r/sites/TurnaroundManagement/Shared%20Documents/03%20Development/Role%20%26%20Permission%20V.2.xlsx?d=wa5e5a9a2071b4ed7b3ef83c4cf0dffd9&csf=1&web=1&e=3stFwC).
* The user is on the **Shutdown Logic** detail page.

---

**Acceptance Criteria**

1. **Scope**: Improve the response time of pasting into the Gantt table, covering:

    1. Pasting large multi-cell (NxN) arrays from an external source or from within the grid (ETM-2615 AC 1–2).
    2. Validation of pasted cells, including master-data checks and Manpower Resource rules (ETM-2615 AC 3, 4 and 6).
    3. Recalculation after paste: Gantt bars, dependency lines, POB / Man-hours, Manpower Histogram and roll-ups to Work, Work Header and Platform rows (ETM-2615 AC 5).
    
2. **No Functional Regression**: Paste results, validation and partial-success rules, and Draft State persistence work the same as before (Aligned with [ETM-7609](https://pttep.atlassian.net/browse/ETM-7609) AC 8).

---

**UI Design**
