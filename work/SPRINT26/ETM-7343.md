# ETM-7343 [Improvement] Daily Report - Actual (%) Font Color Based on Plan Progress
Status: Open
Subtasks: ETM-7475 [FE] Update UI [Open], ETM-7476 [FE] Unit test [Open], ETM-8007 [QA] Create Test Case Manual Test [Open], ETM-8009 [QA] Execute Test Case [Open]
Links: Relates ETM-8012

## Description
**As a** Turnaround Manager or Job Owner  
**I want** the Actual (%) value in the Daily Report to change font color when it is behind the plan  
**So that** I can quickly see which tasks are behind schedule during the daily meeting.

Ref: [ETM-4121](https://pttep.atlassian.net/browse/ETM-4121)

---

**Pre-Conditions**

* The user is logged into the STMS application and possesses the **View All Daily Report Item** or **View Active Daily Report Item** permission in [Role & Permission](https://pttep.sharepoint.com/:x:/r/sites/TurnaroundManagement/Shared%20Documents/03%20Development/Role%20%26%20Permission%20V.2.xlsx?d=wa5e5a9a2071b4ed7b3ef83c4cf0dffd9&csf=1&web=1&e=3stFwC).
* The user is on the **Daily Report** page.

---

**Data Source**

* **Input Progress Table**: `Plan (%)` (calculated from the Shutdown Logic schedule for the active execution date, [ETM-4121](https://pttep.atlassian.net/browse/ETM-4121)) and `Actual (%)`.

---

**Acceptance Criteria**

1. **Actual (%) Font Color Rules**:

    1. `Actual (%)` < `Plan (%)` → **red** font.
    2. `Actual (%)` ≥ `Plan (%)` and `Actual (%)` ≠ 100% → **green** font. This includes `Plan (%)` = 0% and `Actual (%)` = 0%.
    3. `Actual (%)` = 100% → **black** font (default).
    
2. **Levels**: The rule applies to every level in the table: Platform, Work Header, Work and Work Breakdown.
3. **Real-time Update**: The color updates as soon as `Actual (%)` changes ([ETM-4124](https://pttep.atlassian.net/browse/ETM-4124)) and when the user switches the execution date.
4. **No Legend or Filter**: No legend and no "behind schedule only" filter are added.
5. **Export PDF**: The exported PDF ([ETM-5277](https://pttep.atlassian.net/browse/ETM-5277), [ETM-7901](https://pttep.atlassian.net/browse/ETM-7901)) shows the same `Actual (%)` font colors as the screen.
