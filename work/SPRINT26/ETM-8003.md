# ETM-8003 [Improvement] Daily Report - S-Curve Colors (Blue Plan, Orange Actual)
Status: Open
Subtasks: ETM-8536 [FE] Update line color [Open]
Links: Relates ETM-8008

## Description
**As a** Turnaround Manager or Job Owner  
**I want** the S-Curve to use blue for Plan and orange for Actual  
**So that** the chart matches the colors of the progress report we already use.

Ref: [ETM-4127](https://pttep.atlassian.net/browse/ETM-4127)

---

**Pre-Conditions**

* The user is logged into the STMS application and possesses the **View All Daily Report Item** or **View Active Daily Report Item** permission in [Role & Permission](https://pttep.sharepoint.com/:x:/r/sites/TurnaroundManagement/Shared%20Documents/03%20Development/Role%20%26%20Permission%20V.2.xlsx?d=wa5e5a9a2071b4ed7b3ef83c4cf0dffd9&csf=1&web=1&e=3stFwC).
* The user is on the **Daily Report** page.

---

**Acceptance Criteria**

1. **Planned S-Curve**: The Plan line ([ETM-4127](https://pttep.atlassian.net/browse/ETM-4127) AC 3) changes from yellow to **blue**. It stays a dashed line.
2. **Actual S-Curve**: The Actual line ([ETM-4127](https://pttep.atlassian.net/browse/ETM-4127) AC 4) changes from green to **orange**. It stays a solid line.
3. **Related Elements**: Data points, data labels and the legend use the same color as their line.
4. **Export PDF**: The S-Curve in the exported PDF ([ETM-5277](https://pttep.atlassian.net/browse/ETM-5277), [ETM-7901](https://pttep.atlassian.net/browse/ETM-7901)) uses the same colors.
5. **Out of Scope**: Other Daily Report colors (Gantt chart bars, Actual (%) font colors) do not change.
