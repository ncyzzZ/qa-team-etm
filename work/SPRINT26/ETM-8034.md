## Description
**As a** Turnaround Manager  
**I want to** highlight rows and change the text color of rows in the Shutdown Logic Gantt table  
**So that** I can flag and mark tasks during planning meetings, and the marks stay for everyone who opens the Shutdown Logic.

Ref: [ETM-2696](https://pttep.atlassian.net/browse/ETM-2696), [ETM-2697](https://pttep.atlassian.net/browse/ETM-2697)

---

**Pre-Conditions**

* The user is logged into the STMS application and possesses the **Edit Shutdown Logic Table and Visualization** permission in [Role & Permission](https://pttep.sharepoint.com/:x:/r/sites/TurnaroundManagement/Shared%20Documents/03%20Development/Role%20%26%20Permission%20V.2.xlsx?d=wa5e5a9a2071b4ed7b3ef83c4cf0dffd9&csf=1&web=1&e=3stFwC).
* The user is on the **Shutdown Logic** page.

---

**Data Source**

* **Shutdown Logic row (new fields)**: Highlight Color (row background), Text Color.

---

**Acceptance Criteria**

1. **Context Menu Options**:

    1. Right-clicking a row in the Gantt table opens the context menu (Aligned with [ETM-2696](https://pttep.atlassian.net/browse/ETM-2696), [ETM-2697](https://pttep.atlassian.net/browse/ETM-2697)). The menu has two new options above the existing options: **Highlight Row** and **Change Text Color**.
    2. Each option opens a color submenu: the first option is **No Color** (⊘), followed by 13 colors. Highlight Row uses the light palette in [Figma](https://www.figma.com/design/TWffJOBdk9XphbGQOQbNlh/EMI---Turnaround--Shutdown-Logic-2-?node-id=174-811357); Change Text Color uses the strong palette in [Figma](https://www.figma.com/design/TWffJOBdk9XphbGQOQbNlh/EMI---Turnaround--Shutdown-Logic-2-?node-id=204-835335).
    3. Selecting a color applies it to the row. Selecting **No Color** removes that row's highlight or text color and returns it to the default.
    4. The options are available on every level: Platform, Work Header, Work and Work Breakdown.
    5. Users without the **Edit Shutdown Logic Table and Visualization** permission do not see these options, but they can see the colors that were saved.
    
2. **Highlight Row**: The selected color is applied to the background of the whole table row.
3. **Change Text Color**: The selected color is applied to the text of the whole table row.
4. **Condition Colors**: Existing condition colors (e.g. disabled cells, validation errors) are not replaced by the highlight color. They are shown as a layer that mixes with the highlight color.
5. **Saving**:

    1. Highlight and text color changes are saved when the user clicks **Save** (Aligned with [ETM-2310](https://pttep.atlassian.net/browse/ETM-2310)).
    2. Saved colors stay until a user with permission changes them, and all users who open the Shutdown Logic see them.
    
6. **Undo / Redo**: Applying or removing a highlight or text color is recorded in the Undo/Redo history and can be undone and redone (Aligned with [ETM-2703](https://pttep.atlassian.net/browse/ETM-2703)).
7. **Export PDF**: The exported PDF ([ETM-3461](https://pttep.atlassian.net/browse/ETM-3461)) shows the same row highlight and text colors as the screen.
