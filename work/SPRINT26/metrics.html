วิธีอ่าน
  • Defect = issue type Defect (เจอใน QA) · Bug = issue type Bug (หลุดไป UAT/PROD) · นับตาม Sprint ของ defect เอง หารด้วยจำนวน Story ใน sprint นั้น (Story ที่ยกข้าม sprint นับทุก sprint)
  • กันได้ = BA แก้/เพิ่ม AC หรือ dev แก้ก่อนส่ง QA เพราะข้อที่ทีมยก · ยืนยันเดิม = BA ยืนยันพฤติกรรมเดิม ไม่นับว่ากันได้
  • ก่อน / หลัง dev = สถานะ Story ตอนที่ยกข้อนั้น · เตือนแล้วยังเกิด = defect ที่ทีมเคยเตือนไว้แต่ไม่ได้แก้
  • เติมย้อนหลัง = ข้อของการ์ดที่บันทึกหลังเหตุการณ์ (Sprint 26)
  • * = sprint ที่ยังไม่จบ ตัวเลข defect ยังไม่ครบ ห้ามเทียบกับ sprint ที่จบแล้ว
  • สิ่งที่ตัวเลขนี้ไม่ได้พิสูจน์: ความยากและขนาดงานแต่ละ sprint ต่างกัน · การเทสที่ดีขึ้นอาจทำให้ Defect ใน QA เพิ่มขึ้นในขณะที่ Bug ที่หลุดลดลง จึงแสดงทั้งสองเส้น · "-" คือไม่มีข้อมูล ไม่ใช่ศูนย์
