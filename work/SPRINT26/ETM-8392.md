# ETM-8392 [Improvement] Daily Report - Ramp Down and Ramp Up Vertical Lines on Gantt Chart
Status: Open
Subtasks: 
Links: Relates ETM-8008

## Description
**As a** Turnaround Manager or Job Owner  
**I want to** see the Ramp Down and Ramp Up vertical lines on the Daily Report Gantt chart  
**So that** I can tell which work happens before, during and after the shutdown window.

Ref: [ETM-4122](https://pttep.atlassian.net/browse/ETM-4122), [ETM-8042](https://pttep.atlassian.net/browse/ETM-8042)

---

**Pre-Conditions**

* The user is logged into the STMS application and possesses the **View All Daily Report Item** or **View Active Daily Report Item** permission in [Role & Permission](https://pttep.sharepoint.com/:x:/r/sites/TurnaroundManagement/Shared%20Documents/03%20Development/Role%20%26%20Permission%20V.2.xlsx?d=wa5e5a9a2071b4ed7b3ef83c4cf0dffd9&csf=1&web=1&e=3stFwC).
* The user is on the **Daily Report** page.

---

**Data Source**

* **Daily Report**: snapshot Ramp Down Date and Ramp Up Date (date and time), stored when the Daily Report is created ([ETM-8042](https://pttep.atlassian.net/browse/ETM-8042) AC 8.2).

---

**Acceptance Criteria**

1. **Vertical Lines on the Gantt Chart**:

    1. The Daily Report Gantt chart ([ETM-4122](https://pttep.atlassian.net/browse/ETM-4122)) shows a `Ramp Down` vertical line at the Daily Report's snapshot Ramp Down Date and time, and a `Ramp Up` vertical line at the snapshot Ramp Up Date and time.
    2. Line style, header badge and label are the same as the Shutdown Logic vertical lines (Aligned with [ETM-7897](https://pttep.atlassian.net/browse/ETM-7897)).
    3. Only one Ramp Down line and one Ramp Up line are shown (one Plan has one Daily Report).
    4. The lines are shown on the Gantt chart only. The S-Curve does not show them.
    
2. **Display on Every Execution Date**: The lines are shown on every execution date, whether the day is frozen or not.
3. **Extension**: When the last execution day is extended ([ETM-4125](https://pttep.atlassian.net/browse/ETM-4125) AC 8, [ETM-8042](https://pttep.atlassian.net/browse/ETM-8042) AC 8.2), the `Ramp Up` line moves to the new snapshot Ramp Up Date.
4. **Export PDF**: The lines are also shown on the Gantt chart in the exported PDF ([ETM-5277](https://pttep.atlassian.net/browse/ETM-5277), [ETM-7901](https://pttep.atlassian.net/browse/ETM-7901)) when the line's date is inside the exported timeframe.

---

**UI Design**

* **Reference**: same line style as the Shutdown Logic `Ramp Down` / `Ramp Up` lines ([ETM-7897](https://pttep.atlassian.net/browse/ETM-7897)).
* **Design System**: Built using PTTEP Nualta Design System tokens.
