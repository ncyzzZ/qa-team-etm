# ETM-8449 [Improvement] Shutdown Logic - Faster Collapse/Expand of Row Hierarchy
Status: Open
Subtasks: ETM-8537 [FE] Improve performace custom view collapse/expand logic [Done]
Links: Relates ETM-8035

## Description
**As a** Turnaround Manager or Job Owner  
**I want** collapsing and expanding the Platform / Work Header / Work rows in the Shutdown Logic Gantt table to respond faster  
**So that** I can navigate large Shutdown Logic plans without waiting for the table to re-render.

Ref: [ETM-11](https://pttep.atlassian.net/browse/ETM-11), [ETM-2431](https://pttep.atlassian.net/browse/ETM-2431)

---

**Pre-Conditions**

* The user possesses the **View Active Shutdown Logic Item** or **View All Shutdown Logic Item** permission in [Role & Permission](https://pttep.sharepoint.com/:x:/r/sites/TurnaroundManagement/Shared%20Documents/03%20Development/Role%20%26%20Permission%20V.2.xlsx?d=wa5e5a9a2071b4ed7b3ef83c4cf0dffd9&csf=1&web=1&e=3stFwC).
* The user is on the **Shutdown Logic** detail page.

---

**Acceptance Criteria**

1. **Scope**: Improve the response time of:

    1. Manual collapse/expand of a row in the Gantt table (ETM-11 AC 5).
    2. Expand All / Collapse All by data level in the **Custom View** panel (ETM-2431).
    
2. **No Functional Regression**: Collapse/expand behavior, filters, Custom View states and dependency lines work the same as before (Aligned with [ETM-7609](https://pttep.atlassian.net/browse/ETM-7609) AC 8).

---

**UI Design**

* No UI change.
