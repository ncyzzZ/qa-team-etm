# ETM-8393 [Improvement] Shutdown Logic - Capacity and Consumption Tooltip on Manpower Histogram
Status: Open
Subtasks: ETM-8534 [FE] Implement UI [Open], ETM-8535 [FE] Unit test [Open]
Links: Relates ETM-8525

## Description
**As a** Turnaround Manager or Job Owner  
**I want to** see the capacity and consumption when I hover over the Manpower Resource Histogram  
**So that** I can check how many people are needed against the available capacity without counting the scale.

Ref: [ETM-15](https://pttep.atlassian.net/browse/ETM-15)

---

**Pre-Conditions**

* The user is logged into the STMS application and possesses the **View All Shutdown Logic Item** or **View Active Shutdown Logic Item** permission in [Role & Permission](https://pttep.sharepoint.com/:x:/r/sites/TurnaroundManagement/Shared%20Documents/03%20Development/Role%20%26%20Permission%20V.2.xlsx?d=wa5e5a9a2071b4ed7b3ef83c4cf0dffd9&csf=1&web=1&e=3stFwC).
* The user is on the **Shutdown Logic** page.

---

**Data Source**

* **Manpower Resource Histogram** ([ETM-15](https://pttep.atlassian.net/browse/ETM-15)): Capacity line and total assigned manpower per resource row.

---

**Acceptance Criteria**

1. **Tooltip Trigger**: Hovering over a histogram bar shows a tooltip. Moving the mouse away hides it.
2. **Tooltip Content**: The tooltip shows two values for the hovered point in time:

    * **Capacity**: the capacity line value ([ETM-15](https://pttep.atlassian.net/browse/ETM-15) AC 5.2), with a line icon in the capacity line color.
    * **Consumption**: the total assigned manpower ([ETM-15](https://pttep.atlassian.net/browse/ETM-15) AC 5.1), with a box icon in the bar color (red or green per [ETM-15](https://pttep.atlassian.net/browse/ETM-15) AC 5.3).
    
3. **Tooltip Segment**: One tooltip covers a continuous section of the bar with the same height. When the height changes, the next section shows its own values.
4. **Out of Scope**: The tooltip does not list the Works that use the resource.
