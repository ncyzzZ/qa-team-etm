# Draft test cases - ETM-7351 Equipment Mob Plan - Table Copy and Paste Support

Story: ETM-7351 [Improvement]. Source: `story.md` (frozen exam copy, no comments), `docs/modules/equipment-mob-plan-validation.md`, `equipment-mob-plan-figma.md`, `knowledge/`. No `analyst.md` and no `inspector.md` exist for this run: the AC ids below are numbered by the Story's own numbering (AC-1.1 = Story AC 1, item 1).
Existing [QA] subtasks: none known (not read).
Priority: the Story has none, so priority is set by damage if it breaks.
Common precondition: user is logged in as Turnaround Manager (TM, has Edit Equipment Mob Plan); the Equipment Mob Plan page of a Plan opened from Planning tab > Equipment Mob Plan > View Equipment Mob Plan; at least one Work Header exists. Work Header A holds 3 equipment rows, Work Header B holds 2 equipment rows, Work Header C holds 0 equipment ("No equipment added."). Role JO = Job Owner (view only). Test data uses made-up values, for example Material Description `Crane Hook A1`, WIN# `CCU-0001`, Contact Person `Somchai T.`.
Notation: `->` separates action and expected result. "Clipboard block" = tab-separated text, rows on new lines (as copied from Excel). "Last update date" = the date text `Last update on DD Mon YYYY` in the page. Column order of the grid: No., Material Description, WIN# No. (CCU No.), Contact Person, Department, Premob Inspection, Width (m), Length (m), Height (m), Area (m2), Gross Wt. (Tons), Platform, Deck, Item No. in Plot Plan, Transportation, Material Ready at SKL, Require at Offshore, Backload to SKL, Priority, Status, MMR No., Vessel Name, Loading at PSB, Remark.

## Think like the user
- Who: a Turnaround Manager or Job Owner who gets equipment lists from vendors in Excel; they paste whole blocks many times a day during planning, in a hurry, often with messy data.
- Want: put 20 rows in without typing, keep No. and Area correct, know which cells were refused.
- Tired person: pastes while a cell is in edit mode, pastes a block bigger than the table, pastes numbers with 3 decimals or a date in the wrong format, pastes and leaves the page without Save, double-presses Ctrl+V.

## Open questions
1. AC 1.2 says Ctrl+Click and Shift+Click both select; the Story does not say whether Shift+click extends from the focused cell to the clicked cell like Excel. Cases assume yes.
2. Does a paste that exceeds the number of columns (more columns than the grid to the right of the anchor) get cut, rejected or does the modal show? Story is silent. TC-006 writes what a user would call correct (extra columns are ignored) and needs an answer.
3. A clipboard with only one cell pasted while a RANGE of several cells is selected: fill the whole range or only the anchor? Not in the Story.
4. Pasting into the Platform column: which values are "valid"? Story says catalog "under asset"; TC-013 needs a real Platform name of the test event.
5. Deck is a combo-box (dropdown + free text): pasted free text is allowed (truncated to 100), but a value not in the dropdown list is not an enum error. Confirm.
6. Mandatory field pasted with an empty cell: the cell turns red and the modal shows. If the cell was already filled, does the empty paste clear it? Story says "empty input" is invalid, so TC-022 expects blank and red.
7. Area when Width or Length is invalid shows `-`: is that the same character as the empty cell display (hyphen)?
8. Date interpretation: does `31 Feb 2026` count as invalid (assumed yes)? What about 2-digit years, `05 june 2026` lower case month, `5 Jun 2026` (stated as valid), `05/06/2026` (assumed invalid)?
9. Date sequence when only one date is pasted into a row with existing dates: compared with the existing neighbours (the Story says "pasted into a row with existing dates"). TC-020 assumes yes.
10. What happens to a pasted value of Premob Inspection etc. with leading or trailing spaces: trimmed or rejected? Story silent.
11. Does a paste larger than a limit of rows (for example 1000 rows) have a maximum? Story silent (TC-044 uses 200).
12. Edit Mode paste: after the paste, is the cell still in edit mode or does it leave edit mode? Story silent.
13. When the modal is open, are the paste results already visible behind it? Assumed yes (cells applied before the modal).
14. Does Ctrl+Z undo a paste (all cells at once)? Story silent. TC-042 only checks the result is consistent.
15. Does "Last update on" change after Save only on the Planning tab row or also on this page header? TC-034 checks the date text shown after Save.
16. Suggestion (not in Story): Export of the Equipment Mob Plan after paste should show pasted values; not covered by AC.
17. Suggestion (not in Story): Undo (Ctrl+Z) of a paste; paste from a Word or web page table (HTML clipboard); paste on a phone.
18. Suggestion (not in Story): sort and search are not named for paste behaviour.

### TC-001 [FE][MT] Verify cells can be selected by click, drag and Shift+click (POS) [Auto]
Precondition: common
Priority: High
Trace: AC-1.1
1. Click the Material Description cell of the first equipment row under Work Header A. -> The cell shows the focus frame.
2. Drag from that cell to the Contact Person cell of the third row of Work Header A. -> A rectangle of 3 rows x 3 columns is highlighted.
3. Click the Material Description cell of row 1, then Shift+click the Width (m) cell of row 2. -> All cells between the two clicks are highlighted as one rectangle.
4. Click one cell in Work Header B. -> Only that cell is highlighted; the earlier highlight is gone.
Automation: Starting data: Work Header A with 3 rows, B with 2 rows (created by the test through the UI, owned by the test plan). What to check: highlighted cell count per step (1, 9, rectangle, 1). Data set: none. Clean up: delete the created rows or plan. Independent.
