# Draft test cases - ETM-5615 Manpower Mob Plan - Multi-Criteria Grid Filtering

Story: ETM-5615 (frozen exam copy). Source: `story.md`, `docs/UI_Map_ETM.md` + `docs/modules/core-*.md`, `equipment-mob-plan.md` (sibling Filter Panel, used only to compare), `knowledge/`. No `analyst.md` and no `inspector.md` for this exam: AC ids below are numbered by the designer from the Story text. Existing `[QA]` subtasks: none given.

Common precondition: user is logged in as Turnaround Manager (TM) on QA and is on the Manpower Mob Plan page of a plan that is Active and has personnel in at least three Resource Categories. The plan data has: several Companies and Departments; every enum value used at least once (Resource Type, Accommodation, D/N Shift, Hot Bed, Transportation Mob and Demob); at least one person with a blank Company and one with a blank Booking No.; names or route numbers that differ only by number size (`x 2` and `x 10`) or by letter case; Mob, Onboard and Demob dates inside the schedule range. If the plan lacks a value, the tester adds it first (UI only). Roles on QA are only TM and JO (JO = view only).

Notation: `->` separates action and expected result. "record" = write the current value down and compare later, never a fixed number. `Panel` = the right-side Filter Panel. `Filter icon` = the icon on the right of the inner grid toolbar next to Custom View.

## AC ids used in this draft

- AC-0.1 No special permission for the filter; Save button and global save only with Edit Manpower Mob Plan.
- AC-0.2 Dropdowns sort A-Z (dictionary style).
- AC-0.3 All filters give zero records: grid shows `No data available`.
- AC-0.4 Date boundary = schedule: Earliest Task Start - 7 days to Latest Task End + 7 days.
- AC-1.1 Filter icon toggles the Panel open / closed.
- AC-1.2 Filter, Custom View, Set Route panels are mutually exclusive.
- AC-1.3 Header: title `Filter Panel` left, `Reset` link right.
- AC-1.4 16 accordion sections with chevron.
- AC-1.5 On first open only `Name` is expanded, other 15 collapsed.
- AC-2.1 Filter state is global, shared by all users of the active plan.
- AC-2.2 Multi-select structure: Search input, Select All (indeterminate when partial), value checkboxes.
- AC-2.3 Options: only distinct values present in the plan; enum fields in predefined order; free text A-Z; `(Blank)` below Select All only when blank data exists.
- AC-2.4 Options refresh when the Panel is closed and reopened.
- AC-2.5 Per-field lists (Name, Company, Department, Resource Type, Accommodation, D/N Shift, Hot Bed, Transportation Mob, Route No. Mob, Transportation Demob, Route No. Demob, Dlog Status, Booking No.); Route No. Mob independent of Demob.
- AC-2.6 Default all checked; none checked = 0 rows for that criterion.
- AC-2.7 In-section Search: case-insensitive, substring, trims spaces.
- AC-2.8 Select All toggles all boxes, also those hidden by the search.
- AC-3.1 Mob Date: one `Date` picker, `DD Mon YYYY`, matches Mob Date.
- AC-3.2 Onboard Date range `From` / `To`; stay = [Onboard Date, Demob Date - 1 day]; overlap.
- AC-3.3 Range logic: both, only From, only To, From after To = red border only, no text; both empty = no filter.
- AC-3.4 Demob Date: one `Date` picker, matches Demob Date.
- AC-4.1 Real-time filtering in left table and right schedule together, no Apply button.
- AC-4.2 Empty Resource Category header hidden; Mob Route and Demob Route rows stay.
- AC-4.3 Zero total results across all categories: behaviour pending UI design (conflicts with AC-0.3).
- AC-4.4 Category total POB, Required Manpower rows and POB Chart are not affected by the filter.
- AC-4.5 Save with an active filter saves the whole grid including hidden rows.
- AC-4.6 `Reset`: clears searches, checks all, clears dates, restores all rows locally; page Save is needed to publish.
- AC-4.7 Blue dot on Filter icon when any field is not at default; shown at page open when a saved filter exists; gone when cleared.
