# Draft test cases: ETM-5838 Manpower Mob Plan - Add Routine & Non-Routine Transport Routes

Story: ETM-5838 (frozen exam copy, `story.md`). Source: story.md, module docs (core-architecture, equipment-mob-plan for sibling page habits), knowledge/. No analyst.md or inspector.md exists for this run, so AC ids follow the Story numbering: AC-1.1, AC-1.2, AC-2.1 ... AC-5.3.
Existing [QA] subtasks: none known (not read).
Common precondition: a TM user (can do everything) is logged in; an Active Shutdown Event with a Manpower Mob Plan exists, the Manpower Mob Plan dashboard is open; the Set Route panel has no unsaved rows. Priority: the Story gives none, so it comes from damage if it breaks.
Notation: `->` separates the action from the expected result. Data: Helicopter 12, MSB 30, Vessel 70. Locations in the dropdown: Accommodation, the Field of Asset of the active event, SKL.

## Think like the user
- Who: a Turnaround Manager planning logistics for many weeks; adds many routes in one go, often the same route for several days; low tolerance for lost rows.
- Wants: register vehicle, day or date, direction and seats once, and see the seat totals in the Mob Route / Demob Route rows right away.
- Careless user: leaves Origin or Capacity empty, sets Origin = Destination, types a negative or decimal capacity, adds the 11th routine route for a day, closes the panel without Save, presses Save twice, believes the page Save button also saves routes, or presses the page Save and expects the routes to wait.

## Open questions (not in Story or unclear; each changes an Expected Result)
1. Origin equals Destination (for example both AC): allowed, or blocked with a message? TC-018 writes only what is known.
2. Is a duplicate row (same type, day, direction, origin, destination, capacity) allowed? Assumed allowed because each counts toward the 10 / 30 limit.
3. What message shows when the 11th routine route for a day or the 31st non-routine route for a date is added: block at Add Route, or an error on Save? Text unknown.
4. Can a route be edited or deleted after Save? The Story only says "added or modified" in AC-5.1 but has no delete or edit rule.
5. Close or Cancel of the panel with unsaved rows: asks to confirm, or silently discards? No Close/Cancel text in the Story.
6. Does changing Transportation Type after the user edited Capacity overwrite the capacity with the new default?
7. Which dates may the Non-Routine date picker accept (any date, only the event range, past dates)? What month does it open on when empty?
8. How does a routine route (weekly) show in the timeline: on every matching weekday of the whole plan range? From which start and to which end?
9. The pill badge: is it the SUM of Capacity of all routes of that day and direction? What does a day with only capacity 0 show (0 or nothing)?
10. Required-field validation: message text and when (on Save or on leaving the cell)? What happens to a blank row on Save?
11. Which roles hold Edit Manpower Mob Plan or Edit Route? The Story says "or": is a user with only one of them enough? JO is view only on this team.
12. Does Route No. have to be unique? Is leading/trailing space trimmed?
13. Is the capacity maximum limited (upper bound)? Story says only Integer >= 0.
14. If the active Shutdown Event has no Field of Asset, what do Origin / Destination offer?
15. Suggestion (not in Story): a Delete button per route row, and a confirm when closing the panel with unsaved rows.
16. Suggestion (not in Story): a total count message such as "10/10 routes" next to the table.
