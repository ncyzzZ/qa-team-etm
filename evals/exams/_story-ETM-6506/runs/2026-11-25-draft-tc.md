# Draft test cases: ETM-6506 Optimization Feedback Excel Export

Story: ETM-6506, as a Turnaround Manager I export the optimization feedback error blocks to an Excel file (.xlsx) to share, analyse and archive them.
Source: `story.md` (description frozen before 2026-10-15), `docs/modules/shutdown-logic*.md` (no Optimization Feedback panel text there), `knowledge/`. No analyst.md or inspector.md exists for this exam, so the AC ids below are numbered by this draft from the Story list: AC-1.1 Trigger, AC-1.2 File format, AC-1.3 Non-blocking, AC-2.1 Single worksheet, AC-2.2 Header row, AC-2.3.1 to AC-2.3.6 Columns A to F, AC-3.1 Dynamic filename, AC-3.2 Sanitization.
Existing [QA] subtasks: not read (not given).
Common precondition: Logged in as a Turnaround Manager with the Execute Optimization permission; on the View Shutdown Logic page, the Optimization Feedback panel is open and the latest optimization run returned error blocks. "Export" is the button in that panel.
Notation: `->` separates action and expected result. Sample data names are made up. Open the downloaded file in Excel (or read it with a script).

## Think like the user
- Who: the Turnaround Manager, after a failed run, often. Wants a file to send to a planner or engineer and to keep.
- Wants: every blocker in the panel, readable, with the affected tasks by number and name.
- Careless: clicks Export twice, exports with 300 blockers, a plan name with `/ : & Thai`, exports while a second run is running, edits the file in Excel and expects filter and frozen row.

## Open questions (not in the Story; the answer changes an Expected Result)
1. Q1: When the optimizer returns errors, blockers and hints in the same run, does the file list all of them, in what order (errors, then blockers, then hints)? TC-003 expects the same order as the panel.
2. Q2: Is the timestamp in the filename the local browser time or server time? TC-014 expects the local time of the user.
3. Q3: Plan name longer than the file system limit: is it cut? Is a plan name made only of special characters allowed (file starts `Optimization_Errors_____`)?
4. Q4: Several special characters in a row: each becomes one `_` or are they merged? TC-015 expects one `_` for each character.
5. Q5: What does Header (max 255) do with a longer headline: cut or not cut? TC-005 expects no loss of text up to 255 and asks.
6. Q6: A Severity value outside error / blocker / suspect: what is written? Default `error` is stated only for the `validate_input` stage.
7. Q7: Affected when one task id has no match in the Gantt (deleted task): what is shown?
8. Q8: Does Export show a message when it fails (no network, browser blocks download)? Text not given.
9. Q9: Is the Export button hidden or disabled when the user has no Execute Optimization permission, or is there no panel at all?
10. Q10: Is the Export button disabled when the panel has no error blocks? What is the panel state then?
11. Q11: Text starting with `=`, `+`, `-`, `@` in a cell: is it written as plain text? A user would call correct: shown as typed, never calculated.
12. Q12: Details with several items: separate lines in one cell (line break), wrap text on?
13. Suggestion (not in Story): a success message after the download.
14. Suggestion (not in Story): Export on phone or tablet width.
15. Suggestion (not in Story): column widths set so text is readable without resizing.
