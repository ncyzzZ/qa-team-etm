# Draft test cases - ETM-6379 Manpower Mob Plan - POB Chart Data Table & Visibility

Story: ETM-6379 (frozen exam copy). Source: `story.md`, `docs/modules/manpower-mob-plan.md`, `knowledge/`. No `analyst.md` or `inspector.md` exists for this exam run, so AC ids below follow the Story numbering: AC-1.1 = item 1.1, AC-2.7.1 = item 2.7 first sub-point, and so on.
Existing [QA] subtasks: none known.
Common precondition: logged in as a Turnaround Manager (TM, holds View All Manpower Mob Plan Item and Edit POB Chart); the Manpower Mob Plan dashboard of an Active Plan is open; the POB Chart has three Data Groups named `Civil`, `Mechanical`, `Electrical` with different daily values, and `Civil` has the highest values. Cases that need another role, an empty chart or more data say so in their own precondition.
Notation: `->` separates the action from the expected outcome. Priority comes from damage (the Story gives none).

## Thinking like the user
- Who: Turnaround Manager and Job Owner reading the POB numbers every day, often before a meeting; the TM also edits groups.
- Want: see exact daily numbers under the chart, hide noisy lines to focus, then go back to everything.
- Careless user: unchecks lines and forgets, reloads and expects them back, right-clicks a row as a view-only user, adds a group while lines are hidden, edits the same group as a colleague.

## Open questions
1. Does the Export Chart file contain only the checked lines or all groups? (AC-2.7.3 says Export is disabled at zero lines, so it depends on the visible lines. TC-045 writes the user's view: only the checked lines.)
2. When a user unchecks a group and then edits that group, does the row stay unchecked after the edit? (TC-046 not written as a fixed result; the user's view is "stays unchecked, as the user left it"; used in TC-035.)
3. When the last Data Group is deleted while Hide Table is ON, does the toggle go back to OFF or stay ON and disabled? (AC-1.3 says disabled; state not stated. TC-029 expects disabled and no table.)
4. What message does the user see when editing or deleting a Data Group that another user already deleted? The Story is silent. TC-039 expects a clear message and no crash.
5. How are numbers of 1,000 or more shown in cells (thousand separator)? The Story says integer values only.
6. Does a right-click select (highlight) the row as well as open the menu?
7. Which date range does the table cover (shutdown schedule dates; is the 7 days before and after of the dashboard timeline included)?
8. Does the TM role hold Edit POB Chart? Assumed yes. Only two roles (TM and JO) exist on QA, so the "View Active" role without Edit is JO.
9. After Add Data while Hide Table is ON, is the legend updated with the new group? Written as yes (the legend lists every checked Data Group, AC-1.4).
10. Suggestion (not in Story): a message or hint explaining why Export Chart is disabled when all rows are unchecked.
11. Suggestion (not in Story): behaviour on a phone width.
