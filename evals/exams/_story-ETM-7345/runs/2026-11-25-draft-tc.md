# Draft test cases ETM-7345 Shutdown Timeline - Dashboard Frame Layout, Navigation & Split-Pane Architecture

Story: ETM-7345 (frozen copy, description before 2026-11-17T15:37, comments up to 11 Nov 2026).
Source: `story.md` (no analyst.md or inspector.md in this exam; AC ids below are numbered by the Story: AC-2.5 = AC item 2, sub-item 5), `docs/modules/shutdown-timeline.md`, `shutdown-timeline-validation.md`, `.claude/team/knowledge/`.
Existing `[QA]` subtasks: none given.
Notation: TM = Turnaround Manager (View Timeline, Update Progress and Note, Edit Plan). JO = Job Owner (View Timeline only). Priority comes from damage (the Story gives none).

Common precondition: QA environment, user logged in. Three Shutdown Events exist whose Timeline badge shows `Major SD`, `Medium SD`, `Minor SD` (made-up names: `Exam Major Event`, `Exam Medium Event`, `Exam Minor Event`), each with a valid Shutdown Date. The test opens `Shutdown Event List`, selects the event and clicks the `Timeline` tab. Unless a case says otherwise the user is TM. Data-changing cases use their own spare event and restore it.

## Think like the user (3 lines)
- Who: TM plans and updates the preparation schedule every week; JO only looks. Both use a wide desktop screen and are often in a hurry.
- Want: see the plan, move the splitter to read more weeks or more details, fold groups they do not need, press `Update Progress` once.
- Careless person: drags the splitter to the extreme and cannot find the way back, folds a group and refreshes before saving, presses `Update Progress` twice, keeps the page open while a colleague saves.

5. Which timezone label or format does the "current week" use when the browser is not UTC+7? Story says all dates use UTC+7; the visible effect of the browser timezone is not written.
6. Where exactly does `Total Actual (%) > 100.0` come from on the main Timeline when the user cannot type in this Story (Actual input is ETM-7349)? Planned as a seeded-data case only if QA can create it from the UI.
7. Is the `Timeline` tab hidden or shown disabled for a user without View Timeline, and what does a direct link show? AC says "cannot see the tab (navigation denied)".
8. Suggestion (not in Story): keyboard operation of the splitter and the group header (Tab, Enter, arrow keys); phone and tablet width; browser zoom 200%.
