# ETM-8388 Test case draft: Shutdown Timeline - Table Copy and Paste Support

Story: ETM-8388 [Improvement] Shutdown Timeline - Table Copy and Paste Support (parent ETM-6971). Source: story.md (with the 17/18 Nov BA bullets), analyst.md, docs/modules/shutdown-timeline.md, shutdown-timeline-validation.md, knowledge/. No Figma (mockup "To be provided"): modal wording is taken from the module doc (`Paste Validation Failed`, `Some pasted values do not meet the validation rules and were not applied.`, button `OK`).
Existing [QA] subtasks: ETM-8570 Create Test Case Manual Test (In Progress), ETM-8572 Execute Test Case Manual Test (Open). Reuse both, no new subtask.
Priority basis: the Story has no priority, so priority comes from damage if it breaks (wrong or lost plan/progress data = High).
Common precondition ("common"): logged in on QA as Turnaround Manager (View Timeline, Update Progress and Note, Edit Plan). A Shutdown Event with an Active plan that has at least 2 Activity Groups, each with at least 4 activities, weekly cells up to the Current Week and some future weeks. Sample activities: `Frozen Work Lists`, `Peer Review and Work Readiness Review`. The test owns a spare plan so Save can be used and the plan restored. Clipboard text is prepared in Excel or a plain text editor: TAB between columns, new line between rows.
Notation: `->` separates action and expected result. "Timeline" = Timeline tab of the event. "Edit Plan" = page `Edit Shutdown Timeline Plan` opened by `[ Edit Plan ]`. "Focus Mode" = cell selected, not typing. "Edit Mode" = cell opened for typing by double-click.

Lessons (section 1 to 10 of lessons-learned.md):

- 2 Filter + sort + search: not relevant, no filter or search on this table.
- 3 Old data after migrations: not relevant, no data migration in Story.
- 4 Strange input: relevant, TC-018, TC-027, TC-028, TC-043.
- 5 Reordering: not relevant, no reorder.
- 6 Linked data: relevant, Plan (%), Group and Total follow a paste (TC-032, TC-041).
- 7 Charts depend on each other: relevant in part, Actual/Plan bars follow pasted weekly values (TC-017, TC-041).
- 8 Same data on many pages: relevant, pasted values must show the same on Timeline after Save (TC-016, TC-047).
- 9 Matrix: relevant, TC-009, TC-018, TC-027, TC-028 loop over tables.
- L-1 sort with numbers: not relevant. L-2 filter choice kept: not relevant. L-3 read too early: applies to automation (wait for paste result before reading, noted in TC-018). L-4 multi-row paste: relevant, TC-011, TC-022, TC-040. L-5, L-6, L-7: not relevant (no collapse, no name duplicates, no picker). L-8 Story text changed: relevant, the 17/18 Nov BA bullets are used and TC-012, TC-024, TC-040 cover them.

2. TC-013: on Timeline, does paste into a cell that is not a Status cell (for example Activity name) do nothing silently?
3. TC-022 (Timeline): Story gives "first row only" for Edit Plan weekly (BA 17 Nov) but is silent for Timeline weekly Actual; the case assumes the same. Confirm.
4. TC-030: Start Date pasted later than End Date: which cell is "not applied", the pasted one only?
5. Non-mandatory cell with invalid pasted value (Action By, Focal Point have no format rule): not reachable, so no case. Confirm none exists.
6. Suggestion (not in Story): two users pasting and saving the same plan at once. Suggestion (not in Story): Ctrl+Z after a paste. Suggestion (not in Story): keyboard navigation (ETM-8550) keys, no AC lists them.
7. Module doc line "Excel paste, keyboard-only not wanted" (ETM-7348) is replaced by this Story? Cases assume yes.
