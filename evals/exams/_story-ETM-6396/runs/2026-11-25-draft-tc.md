## Open questions
1. The template `Manpower_Mob_Plan_Export_Template_V2.xlsx` is the reference for layout; it was not readable here. Which rows are the header rows (Row 1 banner, Rows 2 and 3 headers)? Is there a freeze pane or a column width rule?
2. Which role or account lacks the Export Manpower Mob Plan permission? QA has only TM and JO; TC-003 and TC-004 need such an account.
3. Is the Export button hidden or only disabled in the empty state and for no permission? The Story says hidden for no permission, disabled for empty.
4. Is there a message while exporting and after success (the Equipment Mob Plan shows an Exporting message and a success message)? Texts for failure, deleted plan, and deleted event are not in the Story.
5. If an invalid character appears twice in a row, are two spaces kept (TC-010 expects two)? Does the banner text and the sheet use the sanitised plan name or the saved name?
6. Which fields are optional and which are free text? Which characters can a user type in Name, Company, Department, Route No., Booking No.?
7. Mob Date equal to Onboard Date: the Onboard day shows  (TC-038)? Person with Onboard Date but no Demob Date: does the stay run to the end of the timeline or stay blank? Demob Date before Onboard Date: can it be saved?
8. Two routes of the same mode on one day: summed or one value (TC-028)?
9. Required Manpower: is it a snapshot taken when the plan was made or live from Shutdown Logic (TC-035)? The Story says "snapshotted Resource category". What does a category with no people show?
10. Exporting an Inactive plan by Turnaround Manager: allowed? The Story speaks of the active plan.
11. A negative value of POB Movement: written as a negative number (TC-046 expects `-1`)?
12. Suggestion (not in Story): text starting with `=`, `+`, `-`, `@` in a cell is written as text so Excel does not run it as a formula (TC-024 expects this).
13. Suggestion (not in Story): a maximum number of rows or a time limit for a large plan (TC-026).
